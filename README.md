
# ReFound – Campus Lost & Found Management System

ReFound is a full-stack web application designed to help
college students report, find, and recover lost belongings
within their campus.

## Features

- User registration and login
- Secure JWT authentication
- Report lost and found items
- Upload item images using Cloudinary
- Browse and search reported items
- Submit claims for found items
- Approve or reject claims
- Personal reports and claim management

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Image Storage
- Cloudinary
- Multer

## Installation

### 1. Clone the repository

git clone https://github.com/YOUR_USERNAME/ReFound-Campus-Lost-and-Found.git

### 2. Backend setup

cd backend
npm install

Create a .env file using .env.example
and configure your MongoDB, JWT and Cloudinary credentials.

Start backend:

npm run dev

### 3. Frontend setup

Open another terminal:

cd frontend
npm install

Create a .env file using .env.example.

Start frontend:

npm run dev

## Local URLs

Frontend: http://localhost:5173

Backend: http://localhost:5000
